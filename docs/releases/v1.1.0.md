# CourseFlow 桌面版 1.1.0

迭代11：新增小组日程卡和待办，优化了用户体验

## 本次更新

- 在组队忙闲图点选空档，可带入时段并打开小组日程。默认优先选择同组两节，另一节有人忙时只选当前空档。
- 可手填议程和分工，也可用一段描述生成日程草稿。核对后应用，并预览或导出墨绿日程、简洁清单两种 PNG 日程卡。
- 改进电脑和手机壁纸的布局，提供四套横屏和竖屏背景。假期数据支持从本地导入额外年份。
- 与 Harness 插件共用课表时，插件待办通过「留出时间」确认保存的活动可在桌面课表中查看。

## 下载与使用

下载 `CourseFlow-1.1.0-windows-x64.zip`，用同页的 `SHA256SUMS.txt` 核对文件。完整解压后双击 `CourseFlow.exe`。便携包自带运行环境，附有虚构示例课表、纯背景壁纸和第三方许可证。

升级时可在新版中选择「打开课表」，继续使用已有课表。需要与 Harness 共用数据时，安装插件时指定正在使用的数据目录。

手填议程、冲突检查和导出可在本地完成。使用 AI 拟稿时，配置具备多模态能力的兼容接口并通过自检，再核对生成的草稿。
