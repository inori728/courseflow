# CourseFlow 桌面版 1.2.0

迭代 12 新增课表助手，统一导航与待办。

## 本次更新

- 顶部导航调整为「课表」「助手」「常用功能」。功能页和校对流程可逐步返回。
- 「助手」可切换聊天或课表操作。用自然语言查课、读课表截图、调课、查空档、拟小组日程和导出壁纸。使用指引和按任务展开的例句可离线查看。
- 可以直接告诉助手日期、节次和名称，把一堂补课或一次个人活动加到已保存的课表。助手检查冲突并提供备选时段。核对后确认保存，也可从原消息查看保存记录。
- 新增桌面待办，可记下截止日期和关联课程，为任务选空档后保存为个人活动。与 Harness 插件使用同一数据目录时，可共用课表和待办。

## 下载与使用

下载 `CourseFlow-1.2.0-windows-x64.zip`，用同页的 `SHA256SUMS.txt` 校验。完整解压后双击 `CourseFlow.exe`。Windows x64 便携包自带运行环境，附虚构课表、公开壁纸背景和第三方许可证。升级后可用「打开课表」继续读取原课表。

打开助手即可查看本地指引。要用自由聊天、截图识别或 AI 拟稿，在「AI 接口设置」配置支持文字与图片的兼容接口并通过自检。具体步骤见随包附带的《使用说明》。
