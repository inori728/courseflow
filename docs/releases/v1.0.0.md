# CourseFlow v1.0.0

Windows x64 正式版，汇总迭代 5–9 的功能。此说明不代表发行附件已上线；实际发布状态与下载文件以 GitHub / Gitee 的 Releases 页面为准。

## 本次更新

- **迭代 5：截图识别。** 共用多模态接口设置和数字图片能力自检，支持整图或分块生成可校对草稿，保留部分结果和不确定项。
- **迭代 6：桌面界面。** 导入、应用内周课表、课程列表和输出共用同一份课表；可设置学期、编辑课程、撤销、保存当前文件和另存为。
- **迭代 7：通知调课。** 输入通知生成草稿，支持同名多课次单选、多选、全选及逐条目标。预览冲突后确认修改当前课表，跨周移动保留目标周原有课程，并在周课表定位到调整后的安排。
- **迭代 8：找共同空闲。** 按实际日期对齐成员忙闲信息，提供忙闲卡、可分享的离线点格页、热力图与会议日历。
- **迭代 9：个性化与输出。** 增加电脑和手机壁纸、主题和背景、安全边距、A4 挂图、分享卡、今日课程、Word / 文字 PDF 导入及声明式列映射，提供 Windows 便携包。
- **试用修复。** 改善按钮悬停和禁用状态文字的可读性；普通保存与通知确认直接保存当前课表，另存为提供独立入口；补齐应用内周课表和组队使用指引。

## 下载与使用

发行附件为 `CourseFlow-1.0.0-windows-x64.zip` 和 `SHA256SUMS.txt`。完整解压 ZIP 后运行 `CourseFlow.exe`，保留全部配套文件；无需另装 Python。校验文件提供 ZIP 的 SHA-256 值。

便携包只包含程序、内置虚构示例、文档和许可证，不预置任何使用者的 API 配置、个人课表、使用记录或原始图片。首次打开可导入自己的数据或主动加载虚构示例。需要 AI 功能时，自行配置具备多模态能力、支持文字和图片识别的接口并通过自检。

普通导入、课程编辑、冲突检查、输出和忙闲计算在本地完成。云端 AI 只在使用识图或通知解析时连接所配置的接口；生成的草稿仍须人工核对与确认。

## 验证与限制

- 相同功能代码的 104 项自动化测试和 18 个 CLI 流程通过；Windows 包的独立运行、GUI、Excel / PDF 组件、绘图及组队自检通过。
- Windows 包未签名，尚未在另一台未安装 Python 的电脑完整验收。本机实跑 Python 3.14.6；Python 3.9 做了语法检查，远端兼容性验证状态见 [GitHub Actions](https://github.com/inori728/courseflow/actions)。
- 课程以每天 12 节表示，学期日期和作息需自行核对；任意钟点需映射到学校节次。
- 文字 PDF / Word 依赖可提取的表格文字，扫描 PDF 需转为图片识别；AI 结果可能有误，必须人工确认。
- 点格页可离线分享，尚未提供在线部署地址；内置假期仅覆盖 2026 年，只提醒，不自动修改课表。
