# CourseFlow 使用说明

适用版本：1.0.0 正式版。发布状态和下载附件以 Releases 页面为准。

## 第一次打开

Windows 包先解压整个 `CourseFlow` 文件夹，再运行 `CourseFlow.exe`。源码用户按 README 创建项目独立环境，运行 `Start-CourseFlow.ps1`。初次运行可点「先体验一下」加载示例，保存前不会覆盖原文件。

公开便携包不预置个人课表、API 配置、使用记录或图片；首次使用请自行导入课表，需要 AI 功能时再配置多模态接口。下载包配有 `SHA256SUMS.txt`，可核对完整性。

源码启动器把配置放在项目 `.dev/user-data`；便携 exe 优先使用 exe 同目录的 `data` 文件夹，目录不可写时使用当前用户主目录下的 `.courseflow`。可通过 `COURSEFLOW_HOME` 自选数据目录。下载和开发缓存随项目目录放置，项目在 D 盘时也留在 D 盘。

## 1. 导入

- **文件**：Excel / CSV 可识别有周一至周日表头的课表网格；逐行课程记录可加载声明式适配配置。文字表格、Word 表格和文字 PDF 复用同一解析器。
- **复制与粘贴**：从教务网页或 Excel 复制表格后粘贴，多列之间保留制表符。普通自然语言课程描述应使用手动录入。
- **截图识别**：先连接支持文字和图片识别的多模态 AI。可选整图或四块识别；分块会逐块请求并在失败时保留已识别部分，费用与速度由接口决定。
- **手动 / 分步录入**：填写课名、星期、1–12 范围内的节次、周次和地点。这是本地表单，不调用 AI。

识图会保留读出的周次原文。缺周次、部分内容不清或超出当前学期总周数时会提示人工核对。截图不能代替学校校历，学期日期、总周数和作息须自己确认。

## 2. 校对与保存

导入后直接进入「我的课表」。默认「周课表」按星期和第 1–12 节显示当前周的实际安排，可以切换周次、上一周、下一周或回到本周；点击课块查看完整信息。顶端星期和日期在滚动时保留，左侧显示节次与已有的开始钟点。周次不确定的课程会单独提示，不假设它每周都上。

切到「课程列表」可双击编辑基础课程，也可新增、删除、撤销、设置学期和手动调课。下方显示冲突、待完善项与调整记录数量，点「展开校对详情」查看内容。

「保存当前课表」直接保存当前应用正在使用的课表，不弹另存窗口。新导入的课表默认使用应用本地数据位置；已打开文件则写回该文件。只有主动点「另存为」才选择另一份文件。程序记住保存后的课表位置，下次打开继续显示。

保存现有文件时会创建同名 `.bak`，只保留上一次保存前的内容。保存采用临时文件替换；检测到文件被其他程序改过时会阻止覆盖，请重新打开后核对。重新导入会沿用现有学期，并尝试按“课名 + 星期 + 节次”保留手动标注；匹配不上的标注会提示。

示例里故意有一处课程重叠，用于体验冲突提示。导出前仍应处理真实课表的冲突。

## 3. AI 接口设置

所有 AI 入口统一提示：**请先配置具备多模态能力（支持文字和图片识别）的 AI 接口。**

填写兼容接口地址（通常以 `/v1` 结束）、模型名、提供方需要的 API Key 和超时。选本地 Ollama 时预填 `http://localhost:11434/v1`，Key 可留空，模型仍须自行支持图片。

点「保存并自检」后会发送一张随机四位数字图片。正确读出后缓存能力验证；换地址、模型或 Key 会重新验证。接口认证、额度或限流失败会显示提示，不会循环重试。不要在问题反馈、截图或聊天里公开 Key。

使用云端模型时会发送本次图片或通知，以及通知匹配所需的课程上下文；不会自动发送课表目录里的其他文件。本地处理不需要配置 API。

## 4. 通知调课

点侧栏「调课 / 停课」，在多行输入框粘贴通知，例如：

> 把第7周的体育课调到第9周周五下午两点，时长和地点不变。

点「解析通知」后先核对解析字段，再看下方具体候选。原第 7 周若有周二和周四两次体育，会同时列出：可以选一个、多个或全选，每条候选右侧可独立改目标周、星期、节次。修改上方默认目标后需点「查找 / 刷新候选」，最终以每行目标为准。

「预览修改与冲突」会逐条显示修改前后。都调到同一时间会产生冲突，需要分别安排；缺少原周次、目标星期或时间无法对应节次时，按提示补充。下午两点表示 `14:00`，不是第 2 节。时长不变按学校作息核算；不匹配时要求人工确认节次。

只有点击「确认修改当前课表」才应用草稿；程序直接修改并保存当前课表，同时备份原文件，不再要求另存另一张。确认后自动回到应用内的周课表，切到调整涉及的周次和节次。跨周移动取消原周的对应课次，在目标周增加一课，保留目标周原有课次。手动调整可从「我的课表」进入，无需 API。

## 5. 生成与导出

选「学期总览」或指定周、背景、主题和尺寸。自定义背景可调模糊、亮度、课块不透明度与上下安全边距；点「更新预览」检查效果，再导出到自己选择的目录。

- 学期总览展示原始周课表与周次；指定周视图应用停课、调课和换教室。
- 「导出后设为电脑壁纸」默认不勾选，只有主动勾选才更改 Windows 桌面。
- `.ics` 需要第 1 周周一、学期总周数和所用节次起止时间；默认课前 15 分钟提醒。导入日历前先查看日期和时区。
- A4 挂图可导出横向 PDF 或 300dpi PNG，适合打印；PDF 是图像页面，不支持课程文字检索。
- 分享卡是普通图片；由用户自行发送，本程序不代发。

## 6. 组队找空闲

左侧是**输入成员资料**，右侧是**查询和结果**。顶部“打开课表”只加载当前课表，不会自动把它加入组队；还需要点“把当前课表加入”。没有成员时右侧显示操作说明，“查找空闲”和结果导出按钮不可用。

左侧几个入口的区别：

| 按钮 | 什么时候用 |
|---|---|
| 把当前课表加入 | 把正在编辑的自己的课表作为一名成员加入 |
| 添加成员课表文件 | 手头有其他人的 YAML、Excel、CSV 或截图，校对后加入 |
| 粘贴忙闲卡短码 / 打开忙闲卡文件 | 接收其他人发来的忙闲信息，无需拿到完整课程内容 |
| 导出我的忙闲卡 | 把自己在当前查询周的忙闲信息导出，交给另一位组长；这一步不会自动加入成员列表 |
| 打开零安装点格页 | 没有课表文件的成员手动点出忙碌格，生成短码后自行交给组长 |
| 分享点格页 | 保存一份独立 HTML 文件，发给成员填写；预填所查周次及已有学期 / 作息信息 |

1. 加入当前课表或其他成员文件。截图仍先识别、校对并确认学期，再加入。
2. 组长选好查询周次，点“分享点格页”，选择保存位置，把得到的 `.html` 文件发给成员。成员用浏览器打开，核对预填的学期和周次，填写自己的名称，点出忙碌格并确认后生成卡片。默认两节连选，一格代表一节。
3. 粘贴或打开每位成员的忙闲卡。卡片可重新填写成员名称，重名须区分。
4. 按第一位成员的周次选周、选最短连续节数，点击查找，查看列表与热力图。
5. 选择空闲范围中的实际会议节次，导出 `.ics`；它不会直接创建在线会议或给成员发邀请。

例如要找第 7 周的讨论时间，填“第 7 周 / 至少连续 2 节”，然后点“查找空闲”。如果列表出现“周三 5–8 节”，表示第 5 到第 8 节全员都空闲，可以只选其中的 5–6 节开会。“至少连续 2 节”是最短长度，不是只返回两个格子，也不是两小时；实际钟点由学校作息表决定。

热力图横向为周一到周日，纵向为第 1–12 节。**绿色“空闲”表示已加入的所有成员都空闲；“1 人忙”表示有一人忙，不能作为全员空闲时段；数字越大，忙碌成员越多。** 左右两个页签分别展示空闲清单和同一份数据的网格。

求交按实际日期对齐。未知周次不能算空闲；作息冲突、时区不一致会阻止合并。没有钟点的卡可按节次求交，但导出会议日历需要明确作息。所有人课表空闲也可能有社团等安排，成员应在点格页把这些时间标忙。

找空闲本身是本地计算，不需要 AI；只有导入成员截图时需要已配置的多模态接口。

“分享点格页”在个人课表为空时也可使用。有已加入成员时，学期日期按第一位成员对齐，沿用已有且一致的作息；没有资料时，日期留空，由成员按组长约定填写。分享页不包含任何成员的姓名或已填写忙闲格。转发文件后，预填信息仍保留，不依赖原电脑的文件路径。

`.html` 是让成员打开填写的页面，`.busycard` 是填写后发回的结果。分享功能只把 HTML 保存到本机，不会自动发微信 / QQ，也没有上线网址。电脑上可用浏览器打开，手机上的 HTML 文件打开方式受浏览器和聊天应用限制。

忙闲卡不是加密文件，接收者能读取名称、日期和忙闲安排，但看不到课程名与教室。

## 常见问题

| 情况 | 处理 |
|---|---|
| 识图缺课 / 看错 | 先人工补改；换清晰截图或试分块；不要直接保存未核对结果 |
| 课程到第 19 周，当前学期只有 16 周 | 保留原文，在学期设置确认实际总周数 |
| 图片模型自检失败 | 确认模型支持图片，并检查兼容协议和接口权限 |
| Word / PDF 导入为空 | 当前仅支持可提取的表格文字；扫描页转图片走识图 |
| 组队提示缺少某周 | 请该成员导出覆盖目标日期的卡片 |
| 日历里的旧课程还在 | 本工具只导出文件，不远程同步；按日历应用方式替换旧日历 |
| 便携包换了电脑后 Key 读不了 | Windows Key 与原用户绑定，在新电脑重新配置即可 |
| 没有 GUI / Tk 报错 | 使用带 Tk 的现有 Python / Anaconda；先验证 `python -m tkinter` |

内置节假日仅覆盖 2026 年，只提示可能受影响课程，不会替学校决定补课。其他限制及源码命令见 README。
