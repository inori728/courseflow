# CourseFlow 使用说明

本说明适用于 CourseFlow 桌面版 1.2.0 和 Harness 插件 0.3.0。第 8–9 节保留常用流程和命令速查，第 10 节介绍导航、课表助手和两端待办。下载附件见 GitHub 或 Gitee 的发行页。

## 第一次打开

Windows 包先解压整个 `CourseFlow` 文件夹，再运行 `CourseFlow.exe`。源码用户按 README 创建项目独立环境，运行 `Start-CourseFlow.ps1`。默认显示「课表」。可到「常用功能 → 导入课表 → 先体验一下」加载示例，保存前可以先核对。

公开便携包不预置个人课表、API 配置、使用记录或图片；首次使用请自行导入课表，需要 AI 功能时再配置多模态接口。下载包配有 `SHA256SUMS.txt`，可核对完整性。

源码启动器把配置放在项目 `.dev/user-data`；便携 exe 优先使用 exe 同目录的 `data` 文件夹，目录不可写时使用当前用户主目录下的 `.courseflow`。可通过 `COURSEFLOW_HOME` 自选数据目录。下载和开发缓存随项目目录放置，项目在 D 盘时也留在 D 盘。

## 1. 导入

- **文件**：Excel / CSV 可识别有周一至周日表头的课表网格；逐行课程记录可加载声明式适配配置。文字表格、Word 表格和文字 PDF 复用同一解析器。
- **复制与粘贴**：从教务网页或 Excel 复制表格后粘贴，多列之间保留制表符。普通自然语言课程描述应使用手动录入。
- **截图识别**：先连接支持文字和图片识别的多模态 AI。可选整图或四块识别；分块会逐块请求并在失败时保留已识别部分，费用与速度由接口决定。
- **手动 / 分步录入**：填写课名、星期、1–12 范围内的节次、周次和地点。这是本地表单，不调用 AI。

识图会保留读出的周次原文。缺周次、部分内容不清或超出当前学期总周数时会提示人工核对。截图不能代替学校校历，学期日期、总周数和作息须自己确认。

## 2. 校对与保存

导入后直接进入「我的课表」。默认「周课表」按星期和第 1–12 节显示当前周的实际安排，可以切换周次、上一周、下一周或回到本周；点击课块查看完整信息。顶端星期和日期在滚动时保留，左侧显示节次与已有的开始钟点。周次不确定的课程会单独提示，不假设它每周都上。

切到「课程列表」可双击编辑基础课程，也可新增、删除、撤销、设置学期和手动调课。下方显示冲突、待完善项与调整记录数量，点「展开校对详情」查看内容。

「保存当前课表」直接保存当前应用正在使用的课表，不弹另存窗口。新导入的课表默认使用应用本地数据位置；已打开文件则写回该文件。只有主动点「另存为」才选择另一份文件。程序记住保存后的课表位置，下次打开继续显示。

保存现有文件时会创建同名 `.bak`，只保留上一次保存前的内容。保存采用临时文件替换；检测到文件被其他程序改过时会阻止覆盖，请重新打开后核对。重新导入会沿用现有学期，并尝试按“课名 + 星期 + 节次”保留手动标注；匹配不上的标注会提示。

示例里故意有一处课程重叠，用于体验冲突提示。导出前仍应处理真实课表的冲突。

## 3. AI 接口设置

所有 AI 入口统一提示：**请先配置具备多模态能力（支持文字和图片识别）的 AI 接口。**

填写兼容接口地址（通常以 `/v1` 结束）、模型名、提供方需要的 API Key 和超时。选本地 Ollama 时预填 `http://localhost:11434/v1`，Key 可留空，模型仍须自行支持图片。

点「保存并自检」后会发送一张随机四位数字图片。正确读出后缓存能力验证；换地址、模型或 Key 会重新验证。接口认证、额度或限流失败会显示提示，不会循环重试。不要在问题反馈、截图或聊天里公开 Key。

使用云端模型时会发送本次图片或通知，以及通知匹配所需的课程上下文；不会自动发送课表目录里的其他文件。本地处理不需要配置 API。

## 4. 通知调课

打开「常用功能 → 调课与停课」，点击「识别调课通知」后粘贴通知，例如：

> 把第7周的体育课调到第9周周五下午两点，时长和地点不变。

点「解析通知」后先核对解析字段，再看下方具体候选。原第 7 周若有周二和周四两次体育，会同时列出：可以选一个、多个或全选，每条候选右侧可独立改目标周、星期、节次。修改上方默认目标后需点「查找 / 刷新候选」，最终以每行目标为准。

「预览修改与冲突」会逐条显示修改前后。都调到同一时间会产生冲突，需要分别安排；缺少原周次、目标星期或时间无法对应节次时，按提示补充。下午两点表示 `14:00`，不是第 2 节。时长不变按学校作息核算；不匹配时要求人工确认节次。

只有点击「确认修改当前课表」才应用草稿；程序直接修改并保存当前课表，同时备份原文件，不再要求另存另一张。确认后自动回到应用内的周课表，切到调整涉及的周次和节次。跨周移动取消原周的对应课次，在目标周增加一课，保留目标周原有课次。手动调整可从「我的课表」进入，无需 API。

## 5. 生成与导出

选「学期总览」或指定周、背景、主题和尺寸。自定义背景可调模糊、亮度、课块不透明度与上下安全边距；点「更新预览」检查效果，再导出到自己选择的目录。

- 学期总览展示原始周课表与周次；指定周视图应用停课、调课和换教室。
- 「导出后设为电脑壁纸」默认不勾选，只有主动勾选才更改 Windows 桌面。
- `.ics` 需要第 1 周周一、学期总周数和所用节次起止时间；默认课前 15 分钟提醒。导入日历前先查看日期和时区。
- A4 挂图可导出横向 PDF 或 300dpi PNG，适合打印；PDF 是图像页面，不支持课程文字检索。
- 分享卡是普通图片；由用户自行发送，本程序不代发。

## 6. 组队找空闲

左侧是**输入成员资料**，右侧是**查询和结果**。顶部“打开课表”只加载当前课表，不会自动把它加入组队；还需要点“把当前课表加入”。没有成员时右侧显示操作说明，“查找空闲”和结果导出按钮不可用。

左侧几个入口的区别：

| 按钮 | 什么时候用 |
|---|---|
| 把当前课表加入 | 把正在编辑的自己的课表作为一名成员加入 |
| 添加成员课表文件 | 手头有其他人的 YAML、Excel、CSV 或截图，校对后加入 |
| 粘贴忙闲卡短码 / 打开忙闲卡文件 | 接收其他人发来的忙闲信息，无需拿到完整课程内容 |
| 导出我的忙闲卡 | 把自己在当前查询周的忙闲信息导出，交给另一位组长；这一步不会自动加入成员列表 |
| 打开零安装点格页 | 没有课表文件的成员手动点出忙碌格，生成短码后自行交给组长 |
| 分享点格页 | 保存一份独立 HTML 文件，发给成员填写；预填所查周次及已有学期 / 作息信息 |

1. 加入当前课表或其他成员文件。截图仍先识别、校对并确认学期，再加入。
2. 组长选好查询周次，点“分享点格页”，选择保存位置，把得到的 `.html` 文件发给成员。成员用浏览器打开，核对预填的学期和周次，填写自己的名称，点出忙碌格并确认后生成卡片。默认两节连选，一格代表一节。
3. 粘贴或打开每位成员的忙闲卡。卡片可重新填写成员名称，重名须区分。
4. 按第一位成员的周次选周、选最短连续节数，点击查找，查看列表与热力图。
5. 选择空闲范围中的实际会议节次，导出 `.ics`；它不会直接创建在线会议或给成员发邀请。

例如要找第 7 周的讨论时间，填“第 7 周 / 至少连续 2 节”，然后点“查找空闲”。如果列表出现“周三 5–8 节”，表示第 5 到第 8 节全员都空闲，可以只选其中的 5–6 节开会。“至少连续 2 节”是最短长度，不是只返回两个格子，也不是两小时；实际钟点由学校作息表决定。

热力图横向为周一到周日，纵向为第 1–12 节。**绿色“空闲”表示已加入的所有成员都空闲；“1 人忙”表示有一人忙，不能作为全员空闲时段；数字越大，忙碌成员越多。** 左右两个页签分别展示空闲清单和同一份数据的网格。

求交按实际日期对齐。未知周次不能算空闲；作息冲突、时区不一致会阻止合并。没有钟点的卡可按节次求交，但导出会议日历需要明确作息。所有人课表空闲也可能有社团等安排，成员应在点格页把这些时间标忙。

找空闲本身是本地计算，不需要 AI；只有导入成员截图时需要已配置的多模态接口。

“分享点格页”在个人课表为空时也可使用。有已加入成员时，学期日期按第一位成员对齐，沿用已有且一致的作息；没有资料时，日期留空，由成员按组长约定填写。分享页不包含任何成员的姓名或已填写忙闲格。转发文件后，预填信息仍保留，不依赖原电脑的文件路径。

点格页只生成所填周次的忙闲卡。标记有课或已有安排的格子，没标记的格子会算作空闲。核对学期第 1 周的周一、所填周次和格子后，勾选「我已核对」即可生成卡片。改动日期、周次或忙闲格后需要重新勾选。勾选「两节连选」时会成对标记，例如第 1–2 节或第 3–4 节。

`.html` 是让成员打开填写的页面，`.busycard` 是填写后发回的结果。分享功能只把 HTML 保存到本机，不会自动发微信 / QQ，也没有上线网址。电脑上可用浏览器打开，手机上的 HTML 文件打开方式受浏览器和聊天应用限制。

忙闲卡不是加密文件，接收者能读取名称、日期和忙闲安排，但看不到课程名与教室。

点热力图的绿色空闲格会打开小组日程，自动带入日期和时段。默认优先选同组两节，例如第 3–4 节。另一节有人忙时只选点中的空闲节。取消勾选「优先选同组两节」可以始终只选一节。要把时间留在个人课表，可勾选「点格时添加个人课表活动」再选格，或从空闲清单选「添加到课表」。保存的活动会计入个人忙闲。缺失钟点会带入与已有作息相符的默认值，桌面版可在「学期与作息」设置实际钟点。

## 7. DeepSeek Harness 本地试用

使用独立插件包时，将整个 ZIP 解压到准备长期保留的目录，按下文的[从 Windows 独立插件包安装](#从-windows-独立插件包安装)接入 DeepSeek Harness。插件包自带本地运行环境。只用插件时从空白课表开始，同时使用桌面版时可选择共用数据目录。

### 从源码试用

在项目根目录打开 PowerShell。已安装 DeepSeek Harness 桌面版且项目 Python 环境已就绪时，执行：

```powershell
.\Start-CourseFlow-Harness.ps1 -Demo
```

这个入口调用已安装 Harness 自带的运行时，在浏览器中打开本机界面。项目与 Harness 位于同一盘且安装目录为盘根的 `Deepseek Harness` 时，会自动找到桌面版。其他位置可加 `-HarnessExe "<安装目录>\DeepSeek Harness.exe"`。使用 `-Demo` 时，Harness 配置和 CourseFlow 示例课表集中在项目 `.dev`。需要一起观察桌面端的更新时，在另一个窗口运行 `.\Start-CourseFlow.ps1 -Demo`。

### 在聊天里调课

在 Harness 聊天输入框复制下面这条命令。例子里的「第 4 大节」对应第 7–8 小节。

```text
/courseflow 把第7周周二的体育课调到周五第4大节，地点不变
```

如果匹配到多节同名课，在侧栏勾选要调的课次。核对原安排、新安排和冲突，再点「确认调课」。这里改的是当前课表，点「撤销上一步」可以恢复这次保存。在输入框开头选中 `@CourseFlow` 候选可带入 `/courseflow`。普通对话的执行取决于 Harness 当前模型是否调用插件工具。

### 其他侧栏操作

1. 点聊天输入框下方的日历图标，在右侧打开「CourseFlow 课表」。再次点击即可收起。在「查看周课表」右侧点「设置当前周次」，填入今天是第几周，核对推算出的第 1 周周一并保存。侧栏按课表时区在每周一自动更新周次。查看周课表后，在「课程查询」标题旁点「上一周」或「下一周」。点「刷新课表」读取最新保存的内容。设置周次后会显示今日和下一节课，再设置节次钟点即可收到课前 10 分钟提醒。
2. 在「常用功能 → 调课与停课」粘贴通知。核对课次与安排后点击「确认调课」。
3. 在「常用功能 → 导入课表」选择课表文件或截图，校对后用「确认导入」更新我的课表。截图识别需要在右上角「AI 接口设置」配置多模态接口并完成自检。可以通过聊天命令将附带的截图直接生成壁纸、课表或日历，只有明确要求「更新我的课表」才会写回共用课表。
4. 在「常用功能 → 组队找空闲」逐份添加成员课表、`.busycard` 文件或 CF1 短码，也可以一次选多个文件。粘贴后点「添加短码」就能继续加人。点「下一步」一起查，遇到缺周或待校对资料时会打开成员核对页。只有一个共同周次且未指定日期时，会按该周查找。查询后点绿色格或空闲列表里的时段即可打开小组日程。如需添加个人课表活动或先修改作息，可在「点选空档后」选择对应操作。切换栏目可保留同一会话里的组队结果和日程草稿。
5. 在「常用功能 → 导出」选择壁纸、YAML、ICS 或挂图。勾选电脑或手机壁纸后，在「壁纸背景」选内置背景或本地图片。点「校对导出内容」和「预览导出」，可查看课表叠加到所选背景后的图片。确认生成后，文件保存在共用数据目录的 `harness/exports/`，侧栏可另存副本。
6. 在侧栏确认保存调课、导入或组队活动后，可点上方的「撤销上一步」恢复这次保存前的课表。每份课表保留最近一步，撤完后按钮变灰。桌面端随后修改并保存课表时，已有的撤销项会失效。

### 从 Windows 独立插件包安装

先安装并打开一次与插件兼容的 Windows x64 版 DeepSeek Harness，让它生成桌面配置。解压完整的插件 ZIP 后，退出 Harness，在解压的 `CourseFlow-Harness` 目录中打开 PowerShell。把命令中的安装位置换成实际路径。

```powershell
.\Start-CourseFlow-Harness.ps1 -InstallDesktop -HarnessExe "<Harness 安装目录>\DeepSeek Harness.exe"
```

独立使用时，数据默认放在插件目录下的 `data`。如需共用桌面版课表，安装命令可加上 `-DataDir "<CourseFlow 桌面版数据目录>"`。插件通过目录链接加载，请保留完整解压目录。重新打开 Harness 后，点聊天框下方的日历图标。如需隔离试用，可先用 `-Demo` 启动，并导入随包提供的虚构示例。

### 从源码安装到日常 Harness

先关闭正在运行的 Harness，然后在项目根目录执行下面的命令。传入 CourseFlow 实际使用的数据目录。便携版通常是程序同目录的 `data`。

```powershell
.\Start-CourseFlow-Harness.ps1 -InstallDesktop -DataDir "<CourseFlow 数据目录>"
```

重新打开 DeepSeek Harness，在「插件 → 已安装」可查看「CourseFlow 课表」。插件代码保存在项目目录，安装复用桌面配置现有的包缓存并记录本地链接。更新代码后重新启动 Harness 即可。

## 8. 迭代 11 源码试用

在项目根目录运行 `./Start-CourseFlow.ps1 -Demo` 或 `./Start-CourseFlow-Harness.ps1 -Demo`，即可用虚构课表试用。自用课表与接口配置使用各自的本地数据目录。

### 查课与待办

- Harness「课表」可切换按日卡片和周课表网格，两个视图保留正在查看的周次。已设置学期日期时显示日期范围并标出今天。
- 在侧栏按课名查询，或输入 `/courseflow 下次数据结构在哪上`。程序按实际发生的课次查找，显示日期、节次和教室。同名近似结果会提示补充完整课名。
- Harness「待办」可添加、完成、删除任务，可填写截止日期与关联课程。也可输入 `/courseflow 添加待办 周五前交实验报告` 或 `/courseflow 删除待办 交实验报告`。待办保存在共用数据目录的 `todos.json`。
- 点待办的「留出时间」，在组队结果选空档并确认保存到课表。桌面端打开或刷新同一份课表即可看到该活动。

### 小组日程与卡片

1. 桌面版和 Harness 的组队结果都可以从空档打开「制定小组日程」。带入日期和钟点，可手填事项、地点、议程和分工。前后节次都空闲时，最长 20 分钟的课间可计入；更长的间隔会分开。可在空档内填写精确到分钟的起止时间。
2. Harness 可用 `/courseflow 约四个人讨论小组作业，连续 60 分钟，周三晚优先，最晚周五上课前` 查候选。准备好成员的课表或忙闲卡，或随命令附上。选择更短的方案前，可在侧栏或通过命令确认缩短。选方案后可填写地点，例如 `/courseflow 选方案 A，地点定在研讨室 B302`。
3. 可以在已选时段直接写一段活动描述，点击「AI 拟议程」。事项和说明可留空，AI 会从描述补齐并拟定现场议程、会前分工。描述中写明的地点可带入草稿，已填好的事项、地点、说明和选定时段会保留。成员可以用代号，分工可分给多人、全员或设为待分配。草稿核对后应用。用「AI 改日程」改时间时，程序先核对新时段，再生成可修改的前后对照。
4. 「预览日程卡」可切换墨绿日程和简洁清单，核对时间、地点和议程后导出 PNG。Harness 命令 `/courseflow 导出日程卡` 可导出当前已保存的草稿。

AI 拟稿和重排共用现有多模态接口配置。首次使用会提示保存并自检，通过后可继续操作。手填和出图可离线使用。确认后的日程卡不需要改写课表文件。

忙闲卡缺少钟点时，插件自动带入兼容的个人课表作息或学校默认作息。默认第 7 节为 16:00–16:45，第 8 节为 16:55–17:40。可以直接点格进入小组日程。需要改默认时，先在「点选空档后」选择「先修改本次作息」，再点对应的空档。成员已提供的钟点保留。无法补齐的节次会先提示填写实际时间。

命令 `/courseflow 选空档 周三第3小节 优先连堂 并打开日程` 与默认点格流程相同，`/courseflow 选空档 周三第2大节` 明确选择整个第 3–4 节。选定时段后，可用 `/courseflow 确认组队作息 我的课表`、`/courseflow 确认组队作息 预设` 或 `/courseflow 确认组队作息 {"7":"16:05-16:50"}` 调整本次作息。

### 新壁纸与本地假期数据

内置樱花电车、海边教室、山间静湖和月夜海岸的横竖纯背景。电脑版把卡片集中在左侧，海边教室稍作透视。手机版按日分两列，周日共用一行标题。用「仅手机」或「仅电脑」预览对应样式，再选择保存位置。

额外年份的放假安排可按内置格式存成 JSON，再从本地导入。`year` 是年份。`days` 中每项包含节日 `name`、ISO 日期 `date` 和布尔值 `isOffDay`。导入后放假和调休功能继续只生成提醒。

```powershell
$env:COURSEFLOW_HOME = Join-Path (Get-Location) '.dev/user-data'
python -m courseflow holidays --import-data '<本地放假数据.json>'
```

## 9. 迭代 11 插件命令速查

以下内容用 `/courseflow` 开头，可输入 `/courseflow 帮助` 查看示例。命令和侧栏在同一会话中使用同一份预览。表内写入或导出的确认命令要在核对预览后使用。

| 功能 | 命令内容 |
|---|---|
| 查课与切换视图 | `查今天的课`、`下一节课`、`下次数据结构在哪上`、`查第7周的课`、`上一周`、`下一周`、`按日卡片`、`周课表网格`、`刷新课表` |
| 设置 | `设置当前周次 7` → `确认周次`。`打开 AI 接口设置` 可进入本机表单，`自检 AI 接口` 可检查已保存的配置。Key 填在本机设置表单中 |
| 导入与调课 | `导入课表` 并附上文件，或直接描述调课要求 → `预览` → 必要时 `选课次 1,2` 或 `选课次 全部` → `确认导入` 或 `确认调课`。可用 `撤销上一步` |
| 导出课表、日历和壁纸 | `导出课表`、`导出日历`、`导出 A4 挂图` 或 `导出第7周手机壁纸 背景:海边教室` → `预览` → `确认导出`。可用 `预览手机壁纸背景 海边教室`，也可附图并输入 `导出手机壁纸 用附件作为壁纸背景` |
| 组队与活动 | 附上成员资料或短码并输入 `查第7周共同空闲` → `确认组队` → `选空档 1` 或 `选空档 周二 3-4节` → `确认添加活动 小组讨论 地点:研讨室`。可追加 `并导出日历`，也可用 `刷新组队`、`导出点格页` |
| 待办 | `添加待办 周五前交实验报告`、`查看待办`、`完成待办 交实验报告`、`重新打开待办 交实验报告`、`删除待办 交实验报告` |
| 给待办安排时间 | `给待办 交实验报告 留出时间` → 找到共同空档后用 `选空档 1` → `确认留出时间`。默认使用待办名称作活动名 |
| 小组日程卡 | 选空档后用 `制定小组日程`，或直接描述约事条件。可输入 `查看日程`、`设置日程 事项:复盘 \| 地点:研讨室`、`添加议程 10 \| 复盘错题`、`添加分工 甲/乙 \| 整理例题`、`预览日程卡 简洁清单`、`导出日程卡` |
| AI 日程草稿 | 选好时段后可直接输入 `拟议程 在研讨室 B302 彩排项目汇报，重点核对演示`。要改日程时用 `改日程` 描述变化。核对后可用 `应用日程修改`、`取消日程修改` 或 `撤销日程修改`。缩短方案可用 `确认缩短并选方案 B` |

待办的截止日期用来记录到期日。只有确认写入的活动才占用课表。即使组队时未加入自己的课表，确认活动时也会检查与已有课程和活动的冲突，冲突时需改选时间。

需要按字段校对时，可在命令后传 JSON 对象。`编辑课表` 支持 `semester`、`courses` 和 `selected`，`编辑组队` 支持 `members` 和周次等筛选字段。`编辑日程` 可填写 `title`、`room`、`notes`、`date`、`start`、`end`、`members`、`agenda` 和 `prep`，例如 `编辑日程 {"agenda":[{"minutes":10,"title":"复盘"}]}`。修改 AI 提案可用 `编辑日程修改` 并传入相同字段。

## 10. 迭代 12 课表助手

桌面版与插件都从「课表」「助手」「常用功能」切换。两端都可以从「课表」查看安排，桌面版也可直接在这里编辑和新增课程。导入、调课、组队、小组日程、待办和导出从「常用功能」进入。

1. 打开「助手」，右上角的「使用指引」可直接查看，也可以点开场的「填入示例」后改成自己的要求。
2. 用「聊天」闲聊或问操作方法。切到「课表操作」后可以查课、添加待办或者处理附件。发截图时可说「帮我按这张图生成课表」。进入设置和返回页面时会保留文字、当前模式和附件。
3. 若提示「AI 待配置」，通过「设置 AI 接口」保存兼容接口和模型并完成图片自检，返回助手接着发送。使用云端接口时，近期对话、本次请求及处理需要的上下文会发给已配置的模型。
4. 看回复里的核对或预览入口。比如上传两份课表截图后，先核对成员，再查询共同空档。选择一段空闲时间或接着说明要用哪一段，助手可以继续拟小组日程。确认课表预览后才保存导入和调课。

在「课表操作」里可以直接往已保存的课表添加一次安排。例如「今天第 7、8 节在自习室安排一次社团排练」。也可以说清哪周哪天有一堂补课。助手使用课表的学期和节次检查冲突。点「查看预览」核对，再点「确认新增活动」或「确认新增课程」。返回对话后，原回复可以「查看保存记录」。想先挑时间，可以让助手列出可用空档。钟点无法与节次作息对齐时，按提示补充节次。更多说法见「使用指引 → 助手如何使用 → 参考例句 → 往课表加安排」。

在 Harness 聊天输入 `/courseflow 助手`会打开助手，输入 `/courseflow 帮助`会直接收到命令、助手用法和常用功能三节。助手面板也提供同一份本地指引。

### 两端共用待办

「常用功能 → 待办」可新增、查看、勾选完成、取消勾选或删除任务。可选填截止日期和关联课程。使用同一数据目录时，两端复用已有的 `todos.json`。在一端保存后，另一端打开或刷新列表即可查看。

点击「留出时间」可进入组队查询并选空档。桌面端查询时会包含自己的课表。选定时间和地点后核对并确认写入个人活动。截止日期用于记录到期日，待办完成状态由勾选管理。

## 常见问题

| 情况 | 处理 |
|---|---|
| 识图缺课 / 看错 | 先人工补改；换清晰截图或试分块；不要直接保存未核对结果 |
| 课程安排超过「学期总周数」 | 在桌面版「我的课表 → 学期与作息」按校历设置学期总周数，保存当前课表后重新查询。查询周次决定这次查哪一周 |
| 图片模型自检失败 | 确认模型支持图片，并检查兼容协议和接口权限 |
| Word / PDF 导入为空 | 当前仅支持可提取的表格文字；扫描页转图片走识图 |
| 组队提示缺少某周 | 请该成员导出覆盖目标日期的卡片 |
| 日历里的旧课程还在 | 本工具只导出文件，不远程同步；按日历应用方式替换旧日历 |
| 便携包换了电脑后 Key 读不了 | Windows Key 与原用户绑定，在新电脑重新配置即可 |
| 没有 GUI / Tk 报错 | 使用带 Tk 的现有 Python / Anaconda；先验证 `python -m tkinter` |

内置节假日覆盖 2026 年，额外年份可通过第 8 节的本地导入入口补齐。程序只提示可能受影响的课程，补课安排由学校确认。其他限制及源码命令见 README。
